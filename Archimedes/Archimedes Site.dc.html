01 — PIPELINE

Six stages, one document, no export step.

Geometry, materials, boundary conditions, mesh, solve and post-processing live in a single parametric file. Start from a sketch or import from the CAD you already use — Gmsh reads STEP and IGES through its OpenCASCADE kernel, and IFC arrives via ifcopenshell, so imported solids are viewable, taggable and directly editable, not frozen. Change a fillet radius and the mesh, the load set and the result field re-derive from the same tree.
